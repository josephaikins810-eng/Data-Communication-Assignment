Security & Cryptography

Topics 7 and 8 — protecting information in transit and at rest. Summary by AMO AIKINS JOSEPH (PUIT/24210041).

7 The CIA Triad

Information security is often explained using three core goals known as the CIA triad (Confidentiality, Integrity, Availability). Every security control should support one or more of these principles.

C — Confidentiality

Only authorized people can read the data. Prevents eavesdropping and leaks.

  • Encryption (TLS, VPN)
  • Access control & passwords
  • Classification labels

I — Integrity

Data is accurate and unaltered in transit or storage. Detects tampering.

  • Hash functions (SHA-256)
  • Digital signatures
  • Checksums & MACs

A — Availability

Systems and data are accessible when needed. Resists outages and attacks.

  • Backups & redundancy
  • DDoS mitigation
  • Disaster recovery plans

7 Cryptography

Cryptography uses mathematics to transform data so only intended parties can read it or prove it has not been changed. It is the main tool for confidentiality and integrity on networks.

Types of cryptography

Type Keys Examples Use
Symmetric One shared secret key AES, ChaCha20 Fast bulk encryption (Wi-Fi, disk encryption)
Asymmetric Public + private key pair RSA, ECC Key exchange, digital signatures, HTTPS handshakes
Hashing No key (one-way) SHA-256, bcrypt Integrity checks, password storage (with salt)

Common terms

  • Plaintext — readable message before encryption
  • Ciphertext — scrambled output after encryption
  • Key — secret value used to encrypt/decrypt or sign
  • Certificate (TLS) — binds a public key to a domain identity
  • End-to-end encryption — only sender and receiver hold keys (e.g. Signal)
Encryption at rest

Protects files on disk or in databases if hardware is stolen.

Encryption in transit

HTTPS, TLS on email and VPNs — protects data on the wire.

8 Data Security

Data security focuses on protecting digital information throughout its lifecycle: creation, storage, use, sharing, archival, and destruction.

Key practices

  • Classification — label data as public, internal, confidential, or restricted
  • Least privilege — users get only the access they need
  • Data masking / anonymization — hide identities in analytics
  • Secure deletion — wipe or destroy media when data is no longer needed
  • Compliance — laws and policies (e.g. GDPR-style privacy, organizational policy)

Data breaches often expose personal records, financial details, or credentials. Strong encryption, monitoring, and employee training reduce risk.

8 Network Security

Network security protects the infrastructure that moves data—routers, switches, firewalls, wireless access points, and the traffic between them.

Controls & technologies

  • Firewall — filters traffic by rules (allow/deny ports and IPs)
  • IDS / IPS — detect or block suspicious patterns (intrusion detection/prevention)
  • VPN — encrypted tunnel for remote access over public networks
  • Network segmentation — separate guest Wi-Fi from internal servers (VLANs)
  • 802.1X / WPA3 — authenticate users and encrypt wireless LAN traffic
  • Patch management — update firmware and OS to close known vulnerabilities

Common threats on networks

Sniffing

Capturing packets on unencrypted links (mitigated by TLS/VPN).

Man-in-the-middle

Attacker relays traffic between two parties; certificates help detect this.

DDoS

Flood of traffic aimed at making a service unavailable.

8 Cybersecurity

Cybersecurity is the broader practice of defending computers, networks, programs, and data from digital attack, damage, and unauthorized access. It combines data security, network security, and organizational processes.

Domains of cybersecurity

  • Application security — secure coding, testing, updates for web and mobile apps
  • Endpoint security — antivirus, EDR on laptops and phones
  • Identity & access — MFA, SSO, role-based access control
  • Cloud security — shared responsibility between provider and customer
  • Human factor — phishing awareness, social engineering defense

Defense in depth

No single tool stops every attack. Defense in depth layers multiple controls: firewall + encryption + MFA + backups + incident response plan. If one layer fails, others still protect assets.

Quick comparison

Focus Primary concern
Data security The information itself (content, privacy, lifecycle)
Network security Paths and devices that carry data (perimeter, traffic)
Cybersecurity Entire digital environment (people, process, technology)
