# Data Communication Assignment

A multi-page website summarizing Data Communication course topics.

## Project Structure (Step by Step)

| Step | Page | Status |
|------|------|--------|
| 1 | `index.html` — Home, bio, navigation | Done |
| 2 | `topics.html` — Networking, signals, wireless | Done |
| 3 | `telegraph.html` — Morse code, telegraph diagram | Done |
| 4 | `security.html` — CIA triad, cryptography, cybersecurity | Done |
| 5 | `resources.html` — Assignment link, Turnitin, YouTube embed | Done |

## Before You Publish

1. Replace **Your Full Name** and **Student ID** in `index.html`.
2. Add your photo as `assets/images/profile.jpg` (or update the `src` in `index.html` to use `profile.svg`).
3. Update the GitHub link in the footer with your real repository URL.

## View Locally

Open `index.html` in your browser, or use Live Server in VS Code / Cursor.

## GitHub

When Git is installed:

```bash
git init
git add .
git commit -m "Step 1: Home page with bio and navigation"
git branch -M main
git remote add origin https://github.com/josephaikins810-eng/data-communication.git
git push -u origin main
```

Enable **GitHub Pages** in repo Settings → Pages → source: `main` branch.
